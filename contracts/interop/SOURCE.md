# Interop contract schemas

These are the canonical copies of the ecosystem interop schemas described in
[`docs/INTEROP.md`](../../docs/INTEROP.md).

| File | Schema |
| :--- | :--- |
| `howl.interop.v1.schema.json` | `howl.interop/v1`, printed by `<component> interop --json` |
| `howl.result.v1.schema.json` | `howl.result/v1`, the command result envelope |

A component that vendors one of these copies it byte for byte and records
this repository and a commit on `main` in its own `SOURCE.md`.
