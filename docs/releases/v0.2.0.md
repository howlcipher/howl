# Howl v0.2.0

The first published release of the `howl` installer.

## What it installs

The default (`standard`) profile installs the Howl ecosystem 0.2.0 from each
component's published, checksummed GitHub Release:

| Component | Version |
| :--- | :--- |
| HowlFrame | 0.1.0 |
| HowlChangeOps | 0.2.0 |
| HowlPlane (binary) and the HowlPlane engine (wheel) | 0.1.0 |
| HowlWriter | 0.1.0 |

```bash
howl install
howl doctor
```

## Components that talk to each other

Components call each other through command lines and JSON files under the
contract in [`docs/INTEROP.md`](../INTEROP.md). Each publishes
`<component> interop --json`, and `howl doctor` now has an **Interop** section
that fails when an installed component runs a command, flag or schema that
another installed component no longer offers. HowlFrame 0.1.0 predates the
descriptor, so its edges show as warnings until the next HowlFrame release.

## Other changes

- HowlPlane requires HowlChangeOps 0.2.0 or later (machine-readable approval
  results, owner-confirmed approvals).
- The HowlPlane engine's minimum Python is 3.11.
- `go run ./tools/interop-check` resolves every edge for a developer workspace,
  and a nightly workflow runs it strictly against every component's `main`.
