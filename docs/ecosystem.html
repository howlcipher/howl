Howl brings specialized tools together around a common rule: intent is not authority. Each component owns a distinct problem so creative work, factual claims, orchestration and execution do not silently become the same thing.

The Howl CLI installs and maintains registered components. It does not orchestrate AI work.

Architecture / conceptual relationships

Proposals do not authorize effects.

Human objective → HowlPlane

Planning, agent routing, evidence and policy evaluation.

HowlCreate ↔ HowlDream

Intentional invention and controlled speculative experiments. Candidates return for evaluation.

HowlFrame → HowlChangeOps

Capability-bounded runtime and deterministic policy underpin governed change execution.

HowlRelay carries work state and handoffs. HowlWriter communicates reviewed knowledge. The arrows describe responsibilities, not a claim that every pair has a native runtime adapter. HowlDream currently exports advisory artifacts only.

Dream output is data, not authority.

HowlDream cannot deploy, merge, approve or send communications. Its WAKE checks are scoped to supplied facts, source IDs and arithmetic. HowlPlane evaluates work; applicable human and HowlChangeOps gates still govern consequential actions.

Current component directory

Core installation and optional companions.

The standard installer manifest includes HowlFrame, HowlChangeOps, HowlPlane and HowlWriter. Core membership describes installation scope, not production maturity. HowlCreate, HowlDream, HowlRelay and reference applications are separately installed companions.

Create and Dream

Two kinds of exploration.

HowlCreate invents intentionally: it searches for useful concepts through deliberate creative operators and convergence.

HowlDream explores speculatively: it treats outputs as experimental material, compares conditions with a baseline, induces failures, and preserves unresolved claims after checks.

Controlled divergent exploration

HowlDream intentionally explores possibilities that may be incorrect, measures known model failures, and verifies speculative ideas within explicit limits before downstream evaluation. A candidate can deserve investigation while remaining unverified.
